# Security Policy

Use GitHub's **Report a vulnerability** button on the [Security advisories page](https://github.com/TriagePilot/triage-pilot/security/advisories) when available to send a private report to the maintainers. If the button is unavailable, private reporting is not currently available; do not open a public issue or disclose details there.

Include the affected version, impact, and minimal reproduction steps. Exclude credentials, private keys, tokens, and confidential pull request contents.

Do not disclose suspected vulnerabilities publicly until maintainers have confirmed a fix or mitigation.

Supported versions:

| Version | Supported |
| --- | --- |
| latest release | yes |
| older releases | no |
