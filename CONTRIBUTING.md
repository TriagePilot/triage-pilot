# Contributing

## Local Development

```bash
pnpm install
pnpm check
pnpm test
```

## Pull Requests

- Bug reports, feature requests, discussions, and private security reports are welcome.
- External code and documentation contributions are not merged in this repository.
- Do not open pull requests for externally authored product code, documentation, examples, tests, or generated changes.
- Maintainers may adopt a separate contributor-rights policy later before opening external contributions.
- Maintainer-controlled dependency-update pull requests are allowed only from configured automation.
- Dependency updates must document package provenance, license-review results, and any required third-party notices.
- Do not add managed-service deployment files, private operational runbooks, private infrastructure scripts, or provider-specific secrets templates to this public repository.
- Run `pnpm check`, `pnpm test`, and Gitleaks before requesting review.
