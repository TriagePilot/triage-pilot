# Repository social preview

`repository-social-preview.svg` is the editable source. It uses the existing navy (`#063b66`) and teal (`#08b7b6`) palette, system sans-serif type, and synthetic workflow labels only. Edit the SVG text and shapes directly, then export `repository-social-preview.png` at exactly 1280 × 640 with an opaque background.

The PNG is the upload artifact for GitHub Settings → General → Social preview. Keep it under 1 MB and inspect all text and arrows after export. Content stays at least 64 pixels from the edges to allow modest cropping. Export without browser margins or page scaling; verify the PNG dimensions after export.

[GitHub social preview guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview) recommends 1280 × 640 and a file under 1 MB.
